Arco now sets the clock per track itself.

**What's new**

- **A clock per track, on every Mac**: the Music app never changes the output's sample rate by itself, on any macOS — earlier versions only seemed to follow each track on Macs where something else did the switching. Arco now reads each track's own rate from the Music app and sets its output to it: a 44.1 kHz track reaches Roon at 44.1, a 96 kHz track at 96
- At a change of rate Arco pauses the Music app for a moment, changes the clock and starts the track again from its first note — a fresh start in Roon, as before
- When Roon is far behind after a pause, Arco starts afresh from where the Music app is instead of playing on minutes late

**Good to know**

- In Music › Settings › Playback, set *Audio Quality* to **Lossless** (up to 24-bit/192 kHz for hi-res)
- Prefer a fixed rate? `defaults write nl.renebouwmeester.arco ClockPerTrack -bool false` leaves it to Audio MIDI Setup
