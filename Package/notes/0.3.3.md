The right sample rate on every macOS.

- **Arco now reads each track's sample rate from the Music app's own audio log** — the format the Music app actually sets up for playback. On macOS 15 the Music app's AppleScript reported 44.1 kHz for streamed hi-res tracks, so Arco switched to the wrong rate there; the log has it right, on every version
- It knows the next track's rate before it starts (the Music app loads it ahead for gapless playback), so the clock changes right at the start of the track
- Reading the log needs an administrator account on the Mac; without one, Arco asks the Music app as before

Thanks to the first tester for the logs that showed it.
